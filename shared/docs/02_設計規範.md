# 02 · 設計規範

> 新增頁面時照這份做，就會和現有系統自動一致。
> **最快的做法：直接複製 `shared/template.html` 改。** 該範本已內含本文件所有規範。

---

## 1. 每一頁都要有的骨架

### 載入順序（固定，不要調換）

```html
<!-- 樣式 -->
<script src="https://cdn.tailwindcss.com"></script>
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+TC:wght@400;500;700;900&display=swap" rel="stylesheet">
<link rel="stylesheet" href="shared/theme.css">   <!-- 一定要放在 Tailwind 之後 -->

<!-- 設定與身分（config 必須在 guard 之前）-->
<script src="config.js"></script>
<script src="shared/guard.js"></script>
<script src="shared/sso.js"></script>

<!-- 計分與回報 -->
<script src="shared/grading.js"></script>
<script src="shared/report.js"></script>
```

⚠️ **不要在頁面裡自己寫死**後端網址、Firebase 設定、學期日期、單元清單、星等門檻，
一律從 `window.CONFIG` / `window.GRADING` 取用，否則日後改一處會漏改其他頁。

⚠️ **頁面內不要宣告 `const CONFIG`**，會把全站設定整個蓋掉。本頁專屬設定請取名 `PAGE`。

### `shared/theme.css` 已經包辦

版型與配色的**單一來源**。不要再在各頁自己寫方格紙底、紙膠帶、字型 ——
要改全站外觀，改那一支就好。

| 提供的東西 | 內容 |
|---|---|
| 字型 | 全站 Noto Sans TC；`code`／`.keep-mono` 仍為等寬 |
| 底紙 | 方格紙底（`--paper-bg` / `--paper-size` 可調） |
| 手作風 | `.tape` 紙膠帶、`.underline-doodle` 塗鴉底線、`.hl`／`.hl-b` 螢光筆 |
| 動畫 | `.pop` 進場淡入上移 |
| 卡片 | `.card`（舊的 `.glass-card`／`.glass-panel`／`.mc-gui` 也自動統一成白卡）|
| 返回鈕 | `#back-to-hub` 的完整樣式 |
| 深色例外 | `.console` 包住的區塊維持深色（模擬器用）|

換配色只需改 `:root` 的色票變數：

```css
:root{
  --paper-bg: #e7e5e4;   /* 底紙 */
  --ink:      #1e293b;   /* 主要文字 */
  --tape:     rgba(250,204,21,.30);
}
```

### 返回基地（固定左上，每頁只放一顆）

```html
<a id="back-to-hub" href="#" data-hub title="返回闖關基地"
   class="fixed top-4 left-4 z-50 inline-flex items-center gap-1.5 bg-slate-800 text-white
          font-bold text-sm px-3.5 py-2 rounded-full shadow-lg hover:bg-slate-700 transition">← 返回基地</a>
<script>
  /* 目標從 config 取，不要寫死檔名（頁面檔名還帶學期前綴）*/
  document.querySelectorAll('[data-hub]').forEach(a => a.href = CONFIG.HUB_PAGE);
  /* 被嵌入 iframe 時隱藏 */
  if (window.self !== window.top) {
    const b = document.getElementById('back-to-hub'); if (b) b.style.display = 'none';
  }
</script>
```

## 2. 身分：登入與登出「只在闖關基地做」

規則（不要打破）：

- **各頁不得有自己的登入表單**。需要班級／座號／姓名時用 `SSO`。
- **各頁不得有登出鈕**。登出一律回闖關基地做，避免學生在半路登出後進度沒存。
- 身分取不到時導回 `CONFIG.HUB_PAGE?next=原頁`，登入後自動跳回來。

```js
const me = SSO.me();          // 同步，hub 登入時已快取好 → 畫面不會停格
                              // 快取在 sessionStorage：關閉瀏覽器就失效
// 沒快取時（清過瀏覽器資料）才用非同步版本補讀名冊：
const me2 = await SSO.resolve(async (sid) => {
  const snap = await getDoc(doc(db, SSO.ROSTER, sid));
  return snap.exists() ? snap.data() : null;
});
// me = { sid, cls, no, name, key }
```

被嵌在 iframe 裡的頁面會自動略過檢查，交由外層頁負責。

> 驗證碼**不在名冊裡**，學生讀不到。細節見 [05 安全性](05_安全性.md)。

## 3. 進度回報：一律走 `shared/report.js`

關卡通關時**必須**回報，否則 hub 永遠不會亮燈、星星永遠是 0。
不要自己拼 Firestore 路徑。

```js
// 初始化一次（各頁 SDK 版本不同，所以由頁面注入函式）
REPORT.configure({ db, doc, getDoc, setDoc, arrayUnion });

// ① 一次性關卡：logic / search / sort / arduino
await REPORT.pass('logic', { stars: 3, score: 100 });

// ② 累加型：ethics 章節、flowchart 單元、thinking 小關、scratch 關卡
//    同一單元重複挑戰只留最好的，stars 自動加總、level 自動更新
await REPORT.unit('ethics', '5-2', {
  star: GRADING.ethicsStar(rate), score: rate,
  extra: { duration: '04:12', correct: 12, total: 13 }   // 只寫進 history
});

// ③ 讀回闖關紀錄（證書用）
const list = await REPORT.history('ethics', '5-2');   // 由新到舊
```

`REPORT` 會自動處理 `arrayUnion` 追加 history、計算 `totalStars`、寫 `merge: true`，
並在 history 超過 400 筆時丟掉最舊的。

## 4. 色彩系統

### 中性色：一律用 `slate`（不要用 gray）

| 用途 | 類別 |
|---|---|
| 主要文字 | `text-slate-800` |
| 次要文字 | `text-slate-500` |
| 提示／停用 | `text-slate-300` `text-slate-400` |
| 卡片底 | `bg-white` |
| 區塊底 | `bg-slate-50` |
| 框線 | `border-slate-200` |
| 深色按鈕 | `bg-slate-800` hover `bg-slate-700` |

### 模組代表色

同一個 `moduleId` 全站共用同一個色系，與 hub 卡片一致。
**各學期實際開哪些模組，看該學期 `hub.html` 的 `MODULES`；這裡列的是配色慣例。**

| moduleId | 模組 | 色系 |
|---|---|---|
| `ethics` | 法律倫理／媒體與社會議題 | 上學期 `blue`、下學期 `pink` |
| `thinking` | 運算思維 | `green` |
| `flowchart` | 流程圖 | `emerald` |
| `scratch` | Scratch 程式設計 | `orange` |
| `logic` | 邏輯挑戰 | `violet` |
| `search` | 線性搜尋 | `sky` |
| `sort` | 排序演算法 | `fuchsia` |
| `arduino` | Arduino 延伸挑戰 | `indigo` |
| — | 前導教材（清單學習機） | `teal` |
| — | 參考教材（音階） | `rose` |
| — | 總整理／綜合測驗 | `purple` |

### 語意色（跨模組固定意義，不可挪作他用）

| 意義 | 色系 | 例子 |
|---|---|---|
| 正確／通過 | `emerald` `green` | ✅ 答對、通關標記 |
| 錯誤／未達標 | `red` | ❌ 答錯、驗證失敗 |
| 提示／注意 | `amber` | ⚠️ 警語、提示卡 |
| 星星 | `amber-500` | ⭐ 所有星數 |
| Scratch 積木 | `#ff661a`（清單）`#9966ff`（運算）`#ffab19`（控制） | 模擬積木外觀 |

| 元件 | 規格 |
|---|---|
| 卡片 | `bg-white rounded-2xl border border-slate-200 shadow-sm` |
| 主要按鈕 | `bg-<模組色>-600 hover:bg-<模組色>-700 text-white font-bold rounded-xl` |
| 次要按鈕 | `bg-slate-100 hover:bg-slate-200 text-slate-700 font-bold rounded-xl` |

| 內文字級 | 閱讀類 `text-lg sm:text-xl leading-loose`；一般 `text-sm` |
| 進場動畫 | `.pop`（0.35s 淡入上移） |

## 6. 版面與互動

- 內容寬度：閱讀頁 `max-w-4xl`；雙欄工作頁 `max-w-7xl`
- 雙欄：`grid lg:grid-cols-2 gap-5`，手機自動堆疊
- 手機一律可用（響應式），投影時字級不小於 `text-base`
- **每個畫面只放一顆返回鍵**
- 嵌入 iframe 的頁面：隱藏自己的返回鍵、取消 `min-height`、由外層調整高度

## 7. 深色的唯一用法：`.console`

全站一律淺色方格紙。**唯一允許的深色是「模擬器／控制台」區塊**：

```html
<section class="console p-6">…模擬器內容…</section>
```

保留深色是為了模擬「電子電路／控制台」的情境感（見 Arduino 頁）。
除此之外不要自訂深色底 —— 終端機風、遊戲夜空、麥塊風原本都是深色，
已於 2026-07-27 統一改為方格紙淺色。

各頁的互動元件仍可有自己的個性（立體按鈕、積木、長條圖），
但必須守住：Noto Sans TC 字型、slate 中性色、模組代表色、左上返回基地。

## 8. 新增頁面檢查清單

- [ ] 從 `shared/template.html` 複製起手
- [ ] 載入順序正確：`theme.css` 在 Tailwind 後、`config.js` 在 `guard.js` 前
- [ ] 中性色用 slate，模組色照上表
- [ ] 左上返回基地（只一顆、目標取自 `CONFIG.HUB_PAGE`、嵌入時隱藏）
- [ ] 學生頁必掛 `shared/guard.js` 與 `shared/sso.js`
- [ ] 若涉及星數：一律呼叫 `GRADING` 的函式，不要自己寫死門檻
- [ ] 通關時呼叫 `REPORT.pass()` 或 `REPORT.unit()`，否則 hub 不會亮燈
- [ ] 手機檢視過一次
- [ ] 推送前跑 `python shared/check.py`
