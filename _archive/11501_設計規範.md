# 115 學年度 資訊科技課程網站 · 設計規範

> 新增頁面時照這份做，就會和現有系統自動一致。
>
> **三支共用檔（載入順序固定）**
> ```html
> <script src="11501_config.js"></script>   <!-- 設定：網址、Firebase、學期、單元清單 -->
> <script src="11501_grading.js"></script>  <!-- 計分規則：星等門檻 -->
> <script src="11501_guard.js"></script>    <!-- 身分守門：未登入導回入口（學生頁才需要）-->
> ```
> ⚠️ **不要在頁面裡自己寫死**後端網址、Firebase 設定、學期日期、單元清單、星等門檻，
> 一律從 `window.CONFIG` / `window.GRADING` 取用，否則日後改一處會漏改其他頁。
>
> ⚠️ **`config.js` 要在 `guard.js` 之前載入**。
> （`guard.js` 讀不到 `CONFIG` 時會改用網址檔名推導學期，所以只載入 guard 的頁面也能運作。）
>
> ⚠️ **頁面內不要宣告 `const CONFIG`**，會把全站設定整個蓋掉。本頁專屬設定請取名 `PAGE`。

### 與下學期（course_11502）的關係

| 檔案 | 兩學期的關係 |
|---|---|
| `guard.js` | **內容完全相同**，改一邊就要複製到另一邊 |
| `grading.js` | 只差註解裡的學期編號，計分規則必須一致 |
| `config.js` | 結構相同、值不同（學期、集合、班級密碼、GAS 網址、appId） |
| `firestore.rules` | **同一份**（一個 Firebase 專案只有一份規則，內含上下學期）|

改動上表任何一支時，先想「另一個學期要不要跟」。

## 1. 基礎（每一頁都要有）

## 2. 色彩系統

### 中性色：一律用 `slate`（不要用 gray）
| 用途 | 類別 |
|---|---|
| 主要文字 | `text-slate-800` |
| 次要文字 | `text-slate-500` |
| 提示／停用 | `text-slate-300` `text-slate-400` |
| 卡片底 | `bg-white` |
| 區塊底 | `bg-slate-50` |
| 框線 | `border-slate-200` |
| 深色按鈕 | `bg-slate-800` hover `bg-slate-700` |

### 模組代表色（與 hub 卡片一致，同一模組全站共用）
| 模組 | 色系 | 用在哪 |
|---|---|---|
| ⚖️ 資訊倫理 | `pink` | hub 卡片、頁面重點 |
| 🧠 運算思維 | `green` | hub 卡片、頁面重點 |
| 🐱 程式設計（Scratch） | `orange` | hub 卡片、程式狀態、評分區 |
| 💡 Arduino 延伸挑戰 | `indigo` | hub 卡片 |
| 🧩 流程圖（程式設計頁內） | `emerald` | 流程圖進度、完成標記 |
| 🔰 前導教材（清單學習機） | `teal` | 前導面板 |
| 🎵 參考教材（音階） | `rose` | 參考面板 |

### 語意色（跨模組固定意義，不可挪作他用）
| 意義 | 色系 | 例子 |
|---|---|---|
| 正確／通過 | `emerald` `green` | ✅ 答對、通關標記 |
| 錯誤／未達標 | `red` | ❌ 答錯、驗證失敗 |
| 提示／注意 | `amber` | ⚠️ 警語、提示卡 |
| 星星 | `amber-500` | ⭐ 所有星數 |
| Scratch 積木 | `#ff661a`（清單）`#9966ff`（運算）`#ffab19`（控制） | 模擬積木外觀 |

## 4. 版面與互動

- 內容寬度：閱讀頁 `max-w-4xl`；雙欄工作頁 `max-w-7xl`
- 雙欄：`grid lg:grid-cols-2 gap-5`，手機自動堆疊
- 手機一律可用（響應式），投影時字級不小於 `text-base`
- **每個畫面只放一顆返回鍵**，避免重複操作
- 嵌入 iframe 的頁面：隱藏自己的返回鍵、取消 `min-height`、由外層調整高度

這頁採**深色主題**（`slate-900` 底 + 亮色點綴），與全站淺色風格不同。

> 只保留模擬器區塊維持深色。

## 6. 後端與版本

**Colab 後端只有一本**：`course_11502/11502_backend.ipynb`（上下學期共用）。
`11501_backend.ipynb` 已停用，只剩一頁說明。

原因：兩本寫死同一個 ngrok 靜態網域，免費版一帳號只有一個，誰後啟動誰佔走。

| 前端送出 | 後端讀寫 |
|---|---|
| `term=11501` | `11501-grader` / `11501-scratch-submissions` |
| `term=11502` | `11502-grader` / `11502-scratch-submissions` |

呼叫後端一律帶 `term`（用 `window.CONFIG.TERM`，不要寫死）。

**怎麼知道 Colab 跑的是不是最新版**

後端 `/api/health` 回報 `features` 清單，前端比對 `11501_config.js` 的 `BACKEND_FEATURES`。
新增端點時：後端 `features` 加一個名稱 → 前端 `BACKEND_FEATURES` 加同一個名稱。
`SERVER_VERSION` 純顯示，前端不做判斷，改了不必動前端。
