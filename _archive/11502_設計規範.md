> 新增頁面時照這份做，就會和現有系統自動一致。
> **最快的做法：直接複製 `11502_template.html` 改。** 該範本已內含本文件所有規範。
> 相關共用檔：`11502_grading.js`（計分規則）、`11502_guard.js`（身分守門）

## 1. 基礎（每一頁都要有）

### 只要兩行：字型 + 主題樣式

版型與配色的**單一來源是 `11502_theme.css`**。不要再在各頁自己寫方格紙底、紙膠帶、字型——
要改全站外觀，改那一支就好。

```html
<script src="https://cdn.tailwindcss.com"></script>
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+TC:wght@400;500;700;900&display=swap" rel="stylesheet">
<link rel="stylesheet" href="11502_theme.css">   <!-- 一定要放在 Tailwind 之後 -->
```

`11502_theme.css` 已經包辦：

| 提供的東西 | 內容 |
|---|---|
| 字型 | 全站 Noto Sans TC；`code`／`.keep-mono` 仍為等寬 |
| 底紙 | 方格紙底（`--paper-bg` / `--paper-size` 可調） |
| 手作風 | `.tape` 紙膠帶、`.underline-doodle` 塗鴉底線、`.hl`／`.hl-b` 螢光筆 |
| 動畫 | `.pop` 進場淡入上移 |
| 卡片 | `.card`（舊的 `.glass-card`／`.glass-panel`／`.mc-gui` 也自動統一成白卡）|
| 返回鈕 | `#back-to-hub` 的完整樣式 |
| 深色例外 | `.console` 包住的區塊維持深色（模擬器用）|

要換配色只需改 `:root` 的色票變數：

```css
:root{
  --paper-bg: #e7e5e4;   /* 底紙 */
  --ink:      #1e293b;   /* 主要文字 */
  --tape:     rgba(250,204,21,.30);
}
```

### 身分：登入與登出「只在闖關基地做」

每一個學生頁都必須掛這兩支，缺一不可：

```html
<script src="11502_guard.js"></script>   <!-- 沒登入直接開網址 → 導回入口 -->
<script src="11502_sso.js"></script>     <!-- 身分由入口帶入，不再自己問 -->
```

規則（不要打破）：

- **各頁不得有自己的登入表單**。需要班級／座號／姓名時，用 `SSO.resolve()` 從 `11502-roster` 帶出。
- **各頁不得有登出鈕**。登出一律回闖關基地做，避免學生在半路登出後進度沒存。
- 身分取不到時導回 `11502_hub.html?next=原頁`，登入後會自動跳回來。

```js
const me = SSO.me();          // 同步，hub 登入時已快取好 → 畫面不會停格
// 沒快取時（清過瀏覽器資料）才用非同步版本補讀名冊：
const me2 = await SSO.resolve(async (sid) => {
  const snap = await getDoc(doc(db, SSO.ROSTER, sid));
  return snap.exists() ? snap.data() : null;
});
// me = { sid, cls, no, name, key }
```

被嵌在 iframe 裡的頁面會自動略過檢查，交由外層頁負責。

### 進度回報：一律走 `11502_report.js`

關卡通關時**必須**回報，否則 hub 永遠不會亮燈、星星永遠是 0。
不要自己拼 Firestore 路徑，用共用模組：

```html
<script src="11502_grading.js"></script>   <!-- 星等門檻 -->
<script src="11502_report.js"></script>    <!-- 進度回報 -->
```

```js
// 初始化一次（各頁 SDK 版本不同，所以由頁面注入函式）
REPORT.configure({ db, doc, getDoc, setDoc, arrayUnion });

// ① 一次性關卡：logic / search / sort / arduino
await REPORT.pass('logic', { stars: 3, score: 100 });

// ② 累加型：ethics 章節、flowchart 單元、thinking 小關、scratch 關卡
//    同一單元重複挑戰只留最好的，stars 自動加總、level 自動更新
await REPORT.unit('ethics', '5-2', { star: GRADING.ethicsStar(rate), score: rate });
```

`REPORT` 會自動處理 `arrayUnion` 追加 history、計算 `totalStars`、寫 `merge: true`。

### 返回基地（固定左上，每頁只放一顆）
```html
<a id="back-to-hub" href="11502_hub.html" title="返回闖關基地"
   class="fixed top-4 left-4 z-50 inline-flex items-center gap-1.5 bg-slate-800 text-white
          font-bold text-sm px-3.5 py-2 rounded-full shadow-lg hover:bg-slate-700 transition">← 返回基地</a>
<script>/* 被嵌入 iframe 時隱藏 */
if(window.self!==window.top){var b=document.getElementById('back-to-hub');if(b)b.style.display='none';}</script>
```

## 2. 色彩系統

### 中性色：一律用 `slate`（不要用 gray）
| 用途 | 類別 |
|---|---|
| 主要文字 | `text-slate-800` |
| 次要文字 | `text-slate-500` |
| 提示／停用 | `text-slate-300` `text-slate-400` |
| 卡片底 | `bg-white` |
| 區塊底 | `bg-slate-50` |
| 框線 | `border-slate-200` |
| 深色按鈕 | `bg-slate-800` hover `bg-slate-700` |

### 模組代表色（與 hub 卡片一致，同一模組全站共用）
| 模組 | 色系 | 用在哪 |
|---|---|---|
| ⚖️ 媒體與社會議題（法律倫理） | `pink` | hub 卡片、頁面重點 |
| 🧠 運算思維 | `green` | hub 卡片、頁面重點 |
| 🧩 流程圖 | `emerald` | 流程圖進度、完成標記 |
| 🐱 程式設計（Scratch） | `orange` | hub 卡片、程式狀態、評分區 |
| 🔍 邏輯挑戰 | `violet` | hub 卡片、頁面重點 |
| 🎯 線性搜尋 | `sky` | hub 卡片、頁面重點 |
| ⚔️ 排序演算法 | `fuchsia` | hub 卡片、頁面重點 |
| 💡 Arduino 延伸挑戰 | `indigo` | hub 卡片 |

### 語意色（跨模組固定意義，不可挪作他用）
| 意義 | 色系 | 例子 |
|---|---|---|
| 正確／通過 | `emerald` `green` | ✅ 答對、通關標記 |
| 錯誤／未達標 | `red` | ❌ 答錯、驗證失敗 |
| 提示／注意 | `amber` | ⚠️ 警語、提示卡 |
| 星星 | `amber-500` | ⭐ 所有星數 |
| Scratch 積木 | `#ff661a`（清單）`#9966ff`（運算）`#ffab19`（控制） | 模擬積木外觀 |

## 4. 版面與互動

- 內容寬度：閱讀頁 `max-w-4xl`；雙欄工作頁 `max-w-7xl`
- 雙欄：`grid lg:grid-cols-2 gap-5`，手機自動堆疊
- 手機一律可用（響應式），投影時字級不小於 `text-base`
- **每個畫面只放一顆返回鍵**，避免重複操作
- 嵌入 iframe 的頁面：隱藏自己的返回鍵、取消 `min-height`、由外層調整高度

## 5. 深色的唯一用法：`.console`

全站一律淺色方格紙。**唯一允許的深色是「模擬器／控制台」區塊**，用 `.console` 包起來：

```html
<section class="console p-6">…模擬器內容…</section>
```

保留深色是為了模擬「電子電路／控制台」的情境感（見 `11502_5016b.html`）。
除此之外不要自訂深色底——`11502_search.html`（終端機風）、`11502_sort.html`（遊戲夜空）、
`11502_logic.html`（麥塊風）原本都是深色，已於 2026-07-27 統一改為方格紙淺色。

各頁的互動元件仍可有自己的個性（立體按鈕、積木、長條圖），
但必須守住：Noto Sans TC 字型、slate 中性色、模組代表色、左上返回基地。
