# 2026-08-11 換掉的舊版章節測驗頁

`11501/cyberethics.html`、`11502/social.html` 的舊版本。
各約 1200 行，**自己內嵌了一份題庫和一整套流程**。

## 為什麼換掉

`shared/quiz-engine.js`（545 行，兩學期共用）和 `content/*.js`（題庫）
其實 2026-07 就寫好了，但 hub 一直連著這兩支舊頁 ——
`cyberethics_new.html` / `social_new.html` 沒有任何地方連得到。

結果是：**改題庫改在沒人讀的檔案上**。

2026-08-09 花了一整輪把 300 題的選項改成「長度不會出賣答案」，
改的是 `content/*.js`。兩天後量出來的落差：

| | 學生真的看到的（這兩支） | 改好的 `content/*.js` |
|---|---|---|
| 11501 | 141 題中 **65 題**正解明顯較長 | 140 題中 **0 題** |
| 11502 | 160 題中 **80 題** | 160 題中 **0 題** |

也就是一半的題目可以靠「選最長的」猜對，而那正是那一輪要修掉的東西。

## 換之前比對過

`content/*.js` 是這兩支的**超集**，沒有東西遺失：

- 章節、小節標題、教材文字（notes）一字不差
- 11502：160 題完全對得上
- 11501：舊頁 141 題裡有 1 題（「綜合測驗：遵守 PAPA 理論…」）
  不在小節裡，它在 `review` 章的整章挑戰中 —— 也在
- 畫面元素 id 完全相同（study/quiz/warning 三個畫面、證書七個欄位）

## 這裡的檔案還有用嗎

沒有。留著只是萬一要查「當初學生看到的是什麼版本」。
確認一學期沒問題之後可以整個資料夾刪掉。

⚠️ 不要把它們搬回去。`shared/tests/qbank.test.js` 會掃全部的 HTML，
   任何一支自己內嵌題庫就紅字 —— 那一條就是為了這件事寫的。
