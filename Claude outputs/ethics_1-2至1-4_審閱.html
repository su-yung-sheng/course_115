第 1 段：網路禮儀：建立友善與尊重的環境

網路禮儀（netiquette）在網路世界裡相當重要，對任何一位網路公民而言，網路禮儀無疑是最重要的倫理規範，也就是網路使用者在網路上對其他人應有的禮儀。（小知識：netiquette 是由 net（網路）和 etiquette（禮儀）所組成的複合體字，也就是網路禮儀的意思。）

① 建立友善與尊重的環境：對網路上的網友，要尊重與體諒，營造友善環境。

・網路上發言時，應注意基本的禮貌。在網路環境，請互相尊重，禮貌發言。

・有彼此不禮貌的地方，盡量以私訊的方式提醒對方、理性對話，在群組如同公共場所，要保持應有的禮貌態度。

課本例子：「資訊專題報告群組」裡，麗茹說「大智該不會在打電動？傻眼！」，大智回「妳才隨便抄網路資料就交差吧？」。另一位同學提醒「大家有話好好講」，後來麗茹說：「大智，對不起，不該在群組這麼說你。」

第 2 段：維護系統的安全與個人隱私

② 維護系統的安全與個人隱私：網路是一種公開的環境，所有的互動如同一個虛擬的公共場所，一定要重視個人隱私及系統安全。

・不在網路上暴露個人資訊。例如：私密照片、身分證件、機票或護照等。

・私人訊息或截圖，不輕易公開在公開的平臺上。不隨意截圖或公開私人的訊息，保護當事人的隱私。

・遇到不明的訊息或連結，不任意轉發或分享。未經求證的圖片、訊息、連結等，不隨便轉發、公開散布。

  4. 網路訊息會自動消失（9）

第 3 段：人際互動要正確、簡潔與清楚的表達

③ 人際互動要正確、簡潔與清楚的表達：在網路世界裡，社交互動以虛擬的方式表達情緒或內容，因為有許多便利的表達方式，如貼圖、動畫或符號等，可以更快速地傳遞內容到即時通訊工具中互動。但若是正式的書信互動，仍要以正式的書信格式進行信件往返。因此，一些基本的原則不可忽略：

・郵件主旨及內容要明確，且務必署名，以示對收件者的尊重。

・通訊或貼文，用字遣詞應力求正確且簡潔。

・信件或貼文，應確認無誤，才寄出或張貼。

任何訊息平臺或 App，按下「傳送」鍵前都要檢查，一旦傳送出去就立即到對方的手上了，一定要小心哦！

第 1 段：PAPA 理論是什麼

資訊倫理並非僅止於對個人行為的規範或人際關係的禮儀，也涉及到社會的公平與正義的問題，本質上這些也是資訊倫理的重要議題。要維持資訊社會的和諧，倫理重於法律。

1986 年梅森（Mason）提出 PAPA 理論，主要呼籲要尊重個人隱私權（privacy）、資料正確性（accuracy）、財物所有權（property）及主張資訊近用權（accessibility），此為資訊倫理中重要議題。

小知識：accessibility 也有譯為資訊存取權或使用權，本書一律使用資訊近用權。近用即接近使用的縮寫。以臺灣為例，多年前並非家家戶戶或是人人都有電腦，政府為了推廣電腦的應用，在全臺一百多個偏鄉設置數位機會中心（Digital Opportunity Center，簡稱 DOC），該中心有電腦設備及網路，民眾可以就近到中心使用電腦。因此有人將 accessibility 譯為資訊近用權，資訊近用權就是主張人人都有使用電腦及網路的權力。

1. PAPA 理論是誰提出的？
  1. ★ 梅森（2）
  2. 卡茲（2）
  3. 圖靈（2）
  4. 諾曼（2）
答錯說明：正解是「梅森」。課文寫：1986 年梅森（Mason）提出 PAPA 理論。卡茲是提出「數位落差」一詞的人，不要記混了。
2. PAPA 四個字母分別代表哪四項？

  2. 隱私、安全、所有、近用（8）
  3. 隱私、正確、公開、存取（8）
  4. 專利、正確、所有、近用（8）
答錯說明：正解是「隱私、正確、所有、近用」。P＝隱私權（privacy）、A＝正確性（accuracy）、P＝所有權（property）、A＝近用權（accessibility）。

  2. 販售便宜的電腦設備（9）

第 2 段：P：隱私權（privacy）

隱私權是個人有權決定哪些資料應該保密，哪些可以公開，且不受他人侵犯的權力。倫理與法律僅一線之隔；前者為自律，發自於良知；後者為他律，是外在的制裁力量。要維持資訊社會的和諧與秩序，倫理重於法律，可見尊重隱私是資訊社會非常重要的素養。基於資訊倫理，一個有資訊素養的數位公民應嚴守下列事項：

1. 未經當事人同意，不應將他人個資傳送給第三者。

2. 資訊使用行為，不應侵害他人的隱私。

3. 應避免在網路公共討論區指名道姓討論私人事務。

4. 資訊管理者應該嚴守其專業倫理規範。

生活案例：2020 年流行的新型冠狀病毒肺炎，中央疫情指揮中心每日公布確診病例，都用［案＋數字］（例如：案 1）、大約幾歲、居住在哪一區。同學問老師為什麼不直接公布姓名，老師說：「這就是保護個人隱私及空間隱私。個人資料（如：姓名）受個人資料保護法保護，依法不能任意公布。」

1. 依照課文，「隱私權」是什麼樣的權力？
  1. ★ 個人有權決定資料保密或公開（13）
  2. 政府有權決定公開個人資料（12）
  3. 網站有權決定會員資料用途（12）
  4. 任何人都能查詢他人的資料（12）
答錯說明：正解是「個人有權決定資料保密或公開」。課文寫：隱私權是個人有權決定哪些資料應該保密，哪些可以公開，且不受他人侵犯的權力。決定權在本人，不在政府或網站。
2. 課文說倫理是「自律」，那法律是什麼？
  1. ★ 他律（2）
  2. 良知（2）
  3. 道德（2）
  4. 習俗（2）
答錯說明：正解是「他律」。課文寫：倫理與法律僅一線之隔；前者為自律，發自於良知；後者為他律，是外在的制裁力量。良知是倫理的來源，不是法律。

  2. 經同意後才分享朋友照片（11）
  3. 管理者嚴守專業倫理規範（11）
  4. 不把同學電話給陌生人（10）
答錯說明：正解是「在討論區指名道姓談私事」。課文第 3 點：應避免在網路公共討論區指名道姓討論私人事務。其他三個都是課文鼓勵的做法。
4. 疫情期間公布確診者，為什麼只說「案 54、30 多歲、北部」，而不公布姓名？
  1. ★ 保護隱私且依法不能公布（11）
  2. 病人的名字太長不好記（10）
  3. 確診者姓名還沒有查到（10）
  4. 怕記者寫錯字被罰錢（9）
答錯說明：正解是「保護隱私且依法不能公布」。課文的老師說：這就是保護個人隱私及空間隱私，姓名受個人資料保護法保護，依法不能任意公布。

第 3 段：A：正確性（accuracy）

有些資訊會影響眾人的生活、社會的安寧，甚至國家的安全，可見資訊的正確性何等重要。由於資訊科技及網路的發達，資訊的交換與傳播之速度遠高於傳統社會，不法之徒有可能會利用網路，擾亂社會秩序，甚至危害國家安全。

1. 資訊的精確與否，對我們的生活有極大影響。切勿寄發或轉寄不實、可疑，或是未經查證的郵件及貼文。

3. 從資安的角度來看，維持資訊的正確性，才能避免資訊安全的風險。

新聞快報：新冠肺炎流行之際，人人急需口罩。根據中央疫情指揮中心表示，民眾上網購買口罩，因為在手機 App 輸入資料不完整或錯誤（僅一天，就有七千多筆）而無法完成手續，導致買不到口罩，這個案例也反映資料正確的重要性。

第 4 段：P：所有權（property）

梅森的理論強調尊重他人所有權，包括著作權與專利權，甚至各種商業機密等。對於所有權，數位公民要了解下列觀念：

1. 物各有主，要尊重資源擁有者具處置及利用的權力。

2. 要了解資訊使用行為侵害他人的所有權，要負哪些責任。

若逾越了所有權相關法律，除了引起訴訟，也有違一個和諧資訊社會的期待。一個有秩序的和諧社會，尊重尤甚於法律，這也是把尊重所有權列為資訊倫理的道理。

第 5 段：A：近用權（accessibility）

在資訊時代，人人應該都有使用資訊科技的權力。然而，儘管資訊科技產品已成為現代生活不可或缺的工具，但仍有不少弱勢族群及身處偏鄉的民眾與學童，無法享有使用資訊科技的機會，對這些弱勢者頗不公平，因此有縮短數位落差（digital divide）概念（數位落差一詞為 1995 年卡茲（James Katz）首次提出）的產生。縮短數位落差就是要弭平使用資訊機會不公平的現象。

第 1 段：數位落差的意義

數位落差是指社會上性別、族群、社經地位、居住環境等有差異者，近用數位產品（如：3C 產品、電腦或網路等）的機會不均等。對於未能享用同等資訊科技機會的人，也就不能透過資訊科技獲取資訊或把資訊增值，此種差異可能會使社會的兩極化更趨嚴重，社會財富分配更為不均，學生也因數位落差而影響課業學習。

過去的重點政策是「縮短數位落差近用權」：當時電腦不是普遍可取得的設備，網路分布有城鄉差異，所以要協助偏鄉弱勢取得與使用電腦、建設網路、募集二手電腦普及各地。

第 2 段：從數位落差到數位包容

近年網路技術及數位設備雖普及化，未必能提升偏鄉或弱勢族群使用數位服務的能力。因此相較於過去的硬體設施加強政策，現在更重視各種軟體使用的素養能力，故重新定義數位落差，升級為「數位包容（digital inclusion）」的概念，希望在社會中不受限於身分地位，人人都能接觸不同數位產品和使用數位服務。

現在的新議題是「如何善用硬體、培養軟體應用素養」：現在普遍使用各種數位產品，如手機、平板、各種電腦等設備，要協助大家使用各種網路應用服務，例如網路報稅、數位學習。

第 3 段：縮短數位落差的措施：普及數位平權

目前由行政院「智慧國家推動小組（SMART TAIWAN 2030）」推行的「數位包容」，是用來建立一個沒有差別待遇的資訊社會而推動的政策與活動，希望創造為全民所共享的資訊社會，並透過公共政策方案，以減少特定群體之間的數位機會差異。此政策可分為三項：普及數位平權、培育數位人才、精進數位學習環境。

「普及數位平權」包含：
